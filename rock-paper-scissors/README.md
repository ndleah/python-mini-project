# Rock Paper Scissors GUI 🎮

A fun **Rock Paper Scissors** game with a graphical interface built using **Tkinter**.  
Play against the computer, keep track of your score, and see who is the ultimate champion!

## Game Rules 📝

- The game is between a **player** and the **computer**.
- You can choose one of three options: **Rock**, **Paper**, or **Scissors**.
- The rules are simple:
  - Rock beats Scissors
  - Scissors beats Paper
  - Paper beats Rock
- If both the player and the computer choose the same option, it’s a **tie**.
- The score is updated after each round, and you can choose to play a new game or stop.

## Features ✨

- Graphical interface with Tkinter
- Real-time score tracking
- Input validation for smooth gameplay
- Easy to run and play
