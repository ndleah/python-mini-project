# Student Result Analyzer

## 🛠️ Description

This Python program analyzes a student's academic results using their name, roll number, and marks.

It calculates:
- Total marks
- Average marks
- Grade
- Subjects with marks below 40

## ⚙️ Languages or Frameworks Used

Python

## 🌟 How to run

Open the `student_result_analyzer.py` file with a Python IDE and run the program.

The program uses the following sample student data:

- Name: Aarav
- Roll: 101
- Marks: 88.5, 35.0, 76.0, 92.5, 48.0

### Sample Output

```text
Student: Aarav (Roll: 101)
Total: 340.0, Average: 68.00
Grade: C
Subjects below 40: Subject 2
