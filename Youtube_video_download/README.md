# YouTube Video Downloader

## 🛠️ Description
A Python program that downloads YouTube videos in high resolution using Tkinter GUI or CLI.

## 🚀 Features
- **Non-Blocking Threaded Downloads**: Video downloads run on a background thread so the GUI window remains responsive.
- **Error Handling & Dialogs**: Catches invalid URLs and PyTube errors gracefully with popup notifications.
- **CLI & GUI Modes**: Run via command-line arguments or desktop GUI.

## ⚙️ Requirements
Install required Python packages:
```bash
pip install pytube
```

## 🌟 How to run

### Command Line
```bash
python Youtube_video_download/main.py "https://www.youtube.com/watch?v=VIDEO_ID" [output_dir]
```

### Desktop GUI
```bash
python Youtube_video_download/main.py
```
