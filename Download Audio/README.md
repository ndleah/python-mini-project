# Download Audio

## 🛠️ Description
A Python script that downloads audio streams directly from YouTube videos and converts them to MP3 files.

## 🚀 Features
- **Dynamic Output Resolution**: Automatically saves audio to current/specified output directory without hardcoded placeholder path errors.
- **CLI & Interactive Mode**: Accepts YouTube URLs via command-line arguments or prompts interactively.
- **Resource Lock Prevention**: Safely closes audio clip handles before temporary file cleanup.

## ⚙️ Requirements
Install required Python packages:
```bash
pip install pytube moviepy
```

## 🌟 How to run

### Command Line
```bash
python "Download Audio/Download Audio.py" "https://www.youtube.com/watch?v=VIDEO_ID" [output_dir]
```

### Interactive Mode
```bash
python "Download Audio/Download Audio.py"
```
