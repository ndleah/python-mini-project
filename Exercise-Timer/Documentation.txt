Hello World!!

This CLI Application allows you to avoid continuous time setting while exercising.
Simply input your exercise requirements via the terminal.

Example: You want to do leg lifts for 10 seconds for 10 reps with a 2-second interval:
    "python exercise_cli.py -t 10 -i 2 -r 10"

Options:
    -t, --time      The time you want to hold/exercise (in seconds)
    -i, --interval  The rest interval between reps (in seconds)
    -r, --reps      The number of reps you wish to do
    -p, --prep      Preparation time before the first rep starts (in seconds)

You can also run "python exercise_cli.py --help" for help.

We hope this tool helps you with your workout routine!
